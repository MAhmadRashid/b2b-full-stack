# Ralph Progress Log

## Codebase Patterns
- **Architecture**: Next.js 15 App Router with TypeScript (strict mode) and React 19.
- **Styling**: Vanilla CSS Design System in `src/app/globals.css`. Uses cyber-obsidian tokens (`--bg-main: #07090e`, `--accent-gradient`, etc.). Do NOT use Tailwind unless explicitly requested.
- **Database**: SQLite with Prisma Client singleton in `src/lib/prisma.ts`. Run `npx prisma db push` if schema changes.
- **Authentication**: JWT tokens stored in HTTP-Only cookies (`pulseflow_session`) via `src/lib/auth.ts`.
- **Authorization (RBAC)**: Zero-trust hierarchy (`OWNER` > `ADMIN` > `MEMBER` > `VIEWER`) in `src/lib/rbac.ts`. Always verify permissions on server route handlers.
- **Public API Gateway**: `POST /api/v1/ingest` validates Bearer API keys (`pfl_live_*`) using `bcryptjs` against `ApiKey.hashedKey` and tracks monthly quota limits.
- **Quality Checks**: Run `npx tsc --noEmit` before declaring any story complete.
- **Webhooks**: Sign outbound payloads with HMAC-SHA256 (`crypto.createHmac('sha256', secretKey)`), dispatch in `X-PulseFlow-Signature` header, and record audit trail via `recordAuditLog`.
- **TypeScript / CLI**: Exclude sub-projects (`ralph`) in `tsconfig.json`. On Windows, invoke node scripts or CLI tools via `cmd /c npx ...` to bypass execution policy blocks.
